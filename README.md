# Acan

一个展示杂志的站点。

**仓库里现在是茶几 + 卡册版，这一版要废掉，改成下面「需求」里写的电子书柜。**

## 需求

### 整体形式

杂志以**电子书柜**的形式呈现。

- 书按行排布，**一行放几本由屏幕宽度决定，界面自适应**
- 封面用 `1` 那张图片
- 标题写在**封面下方**
- 多本电子书按**日期从早到晚**排

### 点开之后

- **左边**：封面图呈现，点击可看高清大图
- **右边上方**：txt 的文字内容，**链接可跳转**
- **右边下方**：图片小图，一行几个依旧自适应屏幕，点击可看高清大图

### 图片顺序

**封面1** → 有二封的话**封面2** → **正片** → **花絮**

### 点图看大图

- 图片**再次点击就可以看到放大的图片**
- **电脑端**：滚轮缩放，鼠标拖动查看图片边缘
- **移动端**：两指缩放，单指拖动
- 大图要**本地高清的原图，不要压缩**

### 图片呈现

- 所有图都要能**完整展现**，不要裁掉内容

### 待定

这几处需求里没说清，实现前需要确认：

- txt 里的「备注：」那行要不要显示
- 右边下方的小图网格，正片和花絮是否要分组/分区显示，还是按顺序连排
- 部署到线上时大图用哪一档（本地能用原图，但六本共 740MB，不适合直接进仓库）

## 素材约定

原图放在 `web/data/magazine/<YYYYMMDD 名称>/`，文件夹名以日期开头，日期决定排序。

| 文件名 | 含义 |
| --- | --- |
| `1.jpg`、`2.jpg` | 封面。纯数字文件名就是封面，`1` 是主封面，`2` 是二封 |
| `随便什么 (1).jpg`、`… (2).jpg` | 正片，按括号里的序号排 |
| 其他名字，如 `幕后1.jpg` | 花絮，按名字前缀自动归组 |

再放一个 `.txt`，**文件名就是杂志标题**，内容四行：

```
标题：CHIC八月大片
时间：2026.08.12
简介：这个夏天，她想带着……
备注：实体刊，AB封，6张小卡
```

即上面这个例子里，标题是文件名 `CHIC八月`。**支持链接**，写成 `[文字](网址)` 或直接贴网址。

## 本地预览

双击 `start.bat`，浏览器会打开 `http://localhost:5500/`。

站点用了 ES module 和 fetch，**必须走 http**，直接双击 `web/index.html` 打不开。

## 构建

原图几百 MB，站点读的是压过的产物。

```bash
cd web/tools
npm install          # 只需第一次
node build-magazines.js
```

只想重做某一本，把关键词接在后面：`node build-magazines.js CHIC`。

产物在 `web/data/magazines/`（进 git），原图目录 `web/data/magazine/` 在 `.gitignore` 里。
