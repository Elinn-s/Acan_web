# Acan

一个展示杂志的站点。

**仓库里现在是书柜版（书架 + 立着的书 + 翻页），这一版要废掉，改成下面「需求」里写的茶几 + 卡册。**

## 需求

### 整体形式

不要书柜。改成**卡册**（小卡收集册）形式，摆在茶几上。

小卡就是专辑里附赠的那种照片卡，标准尺寸 55×85mm，卡册一页九个卡位。

### 场景

- 背景是**白色系圆茶几**
- 环境氛围：**阳光明媚、空气清新的午后**
- 视角是**站着往下看**茶几
- 茶几上**散乱放着几本卡册**，卡册之间可以有部分重叠
- 整个画面充满**惬意的生活气息**

`mockup/茶几-卡册.jpg` 是按这段描述画的一张示意图，可以当参考，但**没有经过确认**，构图和道具（茶杯、绿叶、散落的小卡）都不是硬要求。

### 卡册（合起来的时候）

- 封面用 `1` 那张图片
- 标题用 txt 文件的**文件名**
- 卡册的颜色和这本图的**色系对应**
- 多本卡册按**日期从早到晚**排

### 翻开之后

- 里面是**所有正片包括封面**的小卡形式
- 顺序：**封面第一张** → 有二封的话第二张 → 其他正片按顺序往后排
- 小卡**不需要标序号**
- **一页九张小卡，3×3 排布**
- 正片放完后**一页没满也不用硬填**
- **花絮图片另起一页**
- 整体看着就像**小卡收集册**
- txt 的文字内容放在**翻开后第一页的上方**，从上到下按顺序排布，**链接可以跳转**

### 点小卡看大图

- 小卡**再次点击就可以看到放大的图片**
- **电脑端**：滚轮缩放，鼠标拖动查看图片边缘
- **移动端**：两指缩放，单指拖动
- 大图要**本地高清的原图，不要压缩**

### 图片呈现

- 所有图都要能**完整展现**，不要裁掉内容

### 待定

这几处需求里没说清，实现前需要确认：

- 翻开后是一次显示一页（九张），还是像真卡册那样左右两页一起显示（十八张）
- txt 里的「备注：」那行要不要显示（之前说过先不呈现，后来说「txt 的文字内容」放第一页上方）
- 部署到线上时大图用哪一档（本地能用原图，但六本共 740MB，不适合直接进仓库）

## 素材约定

原图放在 `web/data/magazine/<YYYYMMDD 名称>/`，文件夹名以日期开头，日期决定排序。

| 文件名 | 含义 |
| --- | --- |
| `1.jpg`、`2.jpg` | 封面。纯数字文件名就是封面，`1` 是主封面，`2` 是二封 |
| `随便什么 (1).jpg`、`… (2).jpg` | 正片，按括号里的序号排 |
| 其他名字，如 `幕后1.jpg` | 花絮，按名字前缀自动归组 |

再放一个 `.txt`，**文件名就是杂志标题**，内容四行：

```
标题：CHIC八月大片
时间：2026.08.12
简介：这个夏天，她想带着……
备注：实体刊，AB封，6张小卡
```

即上面这个例子里，标题是文件名 `CHIC八月`。**支持链接**，写成 `[文字](网址)` 或直接贴网址。

## 本地预览

双击 `start.bat`，浏览器会打开 `http://localhost:5500/`。

站点用了 ES module 和 fetch，**必须走 http**，直接双击 `web/index.html` 打不开。

## 构建

原图几百 MB，站点读的是压过的产物。

```bash
cd web/tools
npm install          # 只需第一次
node build-magazines.js
```

只想重做某一本，把关键词接在后面：`node build-magazines.js CHIC`。

产物在 `web/data/magazines/`（进 git），原图目录 `web/data/magazine/` 在 `.gitignore` 里。
